# Digital Solutions 2025

Welcome to our text for the QCAA Digital Solutions 2025 syllabus. It brings together the theory, skills and examples we need to plan, build and evaluate our own digital solutions across Years 11 and 12.

## What is Digital Solutions?

In Digital Solutions we learn how to create **digital solutions**: working systems that combine a user interface, data and code to solve real-world problems. Along the way we look at how those solutions affect the people who use them, and how to keep their data private and secure.

We create our solutions by working through a problem-solving process called the **EDGE framework**:

- **explore** → we work out what the problem is, who the users are and what already exists
- **develop** → we plan how our solution will work using design, systems and computational thinking
- **generate** → we build the user interface, code and data components
- **evaluate** → we test our solution against our success criteria and refine it

Our assessments follow the same process. In each one we show our thinking at every stage, not just the finished product.

## How to use this text

The text is organised into chapters. We can work through them in order, or jump to the chapter we need for the task we're working on. We use the menu on the left to move between pages.

- **Introduction** → what digital solutions are, and the software we need to install
- **Coding** → computational thinking, programming features, good coding practice and programming paradigms
- **User Experience** → usability principles, visual communication and the impacts of our designs
- **Data** → data principles, structuring data with normalisation, and managing data
- **Data Transmission** → privacy, networking, and data security management and threats
- **Documentation** → how to produce each part of our assessment folios, from mind maps and user insights to testing, evaluation and appendices
- **Python Skills** → Python techniques for our solutions, including SQLite, JSON, XML and working with APIs
- **SQL Skills** → writing SQL queries to create, read, update and delete data
- **Utilities Skills** → the tools we use alongside our code, such as DB Browser for SQLite and Figma
- **Assessments** → what each assessment asks of us and how to prepare for it

Each page starts with its **Learning Goals**, so we know what we're working towards before we begin. Most pages finish with activities that let us practise what we've learnt. Answers to many of the activities are on the [Activity Answers](activity_answers.md) page. Let's try each activity first, and then check our work.

Code examples have line numbers, and some have highlighted lines to show what's new or changed. The Explanation of Code under each example refers to those line numbers.
