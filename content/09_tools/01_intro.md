# Utilities Introduction

:::{dropdown} Learning Goals
By the end of this section you will:
- know which utilities we use in this course, and what we use each one for
- know where each utility fits in the problem-solving process
:::

Utilities are the software tools we use alongside Python to design, build and document our digital solutions. We don't submit them as part of our solutions, but they help us plan and test our ideas, and produce the diagrams and prototypes in our assessment responses.

Each utility is free for students. See [](../01_introduction/02_technologies_used.md) for how to install or access them.

## Utilities in this course

| Utility | What we use it for | Where it fits |
| --- | --- | --- |
| [](02_db_browser.md) | Creating and viewing SQLite databases, and testing SQL queries before we use them in Python | Develop and Generate |
| [](03_figma.md) | Creating wireframes, mock-ups and interactive, non-coded prototypes of user interfaces | Develop and Generate |
| [](04_drawio.md) | Drawing documentation diagrams, such as data flow diagrams, entity relationship diagrams and use case diagrams | Explore and Develop |

## How the utilities fit together

Using the right tool at each stage saves time and improves the quality of our documentation.

- In **Explore**, we use draw.io for use case diagrams and data flow diagrams to analyse the problem.
- In **Develop**, we design the data with entity relationship diagrams in draw.io, then test the database design and SQL in DB Browser for SQLite. We design the user interface with mock-ups in Figma.
- In **Generate**, we build a non-coded prototype in Figma for a technical proposal, or use DB Browser for SQLite to check the data while we code a digital solution in Python.

:::{tip} Keep your source files
:class: dropdown
Exported images can't easily be changed. Save the `.drawio` and `.db` files in our project folder, and keep the link to our Figma file, so we can update our work after feedback instead of starting again.
:::
